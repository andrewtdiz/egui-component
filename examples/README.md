# Examples

Run examples from the repo root:

```bash
cargo run --example showcase
```

Available examples:

- `showcase`
  Broad component catalog and API preview surface.
- `content-composition`
  Reusable composition patterns with `layout::*`, `Card`, `Label`, `Button`, `Kbd`, and scoped overrides.
- `popup-patterns`
  Popup interaction patterns for `Tooltip`, `DropdownMenu`, and `Dialogue`.
- `theme-playground`
  Live controls for `ThemeSpec`, `ThemeMode`, `theme::set_theme`, `theme::set_mode`, and `theme::with_theme`.

Example commands:

```bash
cargo run --example showcase
cargo run --example content-composition
cargo run --example popup-patterns
cargo run --example theme-playground
```
